# 游戏内世界模拟与多智能体系统

## 项目描述

游戏内世界模拟与多智能体系统的bug修复项目。核心模块 `simulation/world.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 智能体更新完全没做NPC之间没有交互
- 交互完全没做NPC之间不会交流
- 涌现行为完全没做不会出现群体行为
- 群体智能完全没做NPC不会协作
- 世界状态完全没做不知道世界整体是什么样

## 运行测试

```bash
python -m pytest tests/test_world_simulation.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
